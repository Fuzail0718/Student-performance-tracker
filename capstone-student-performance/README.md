# 🎓 Student Performance Prediction Project

A comprehensive machine learning project to predict student academic performance using multiple models including Random Forest, Neural Networks, and LSTM.

## 📋 Project Overview

This project analyzes student academic data to predict performance (Pass/Fail) using various machine learning and deep learning approaches. It includes a complete pipeline from data preprocessing to model deployment.

### Features
- **Data Preprocessing**: Clean and prepare academic data
- **Feature Engineering**: Create meaningful features from student records
- **Multiple Models**: Random Forest, Neural Network, LSTM
- **Model Comparison**: Compare different approaches
- **REST API**: Flask-based API for predictions
- **Interactive Dashboard**: Streamlit dashboard for data exploration
- **Explainability**: Feature importance analysis
